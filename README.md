# Online Feedback Application - DevOps Demo

A lightweight online feedback web application built with Java and HTML to demonstrate a standard DevOps CI/CD workflow incorporating GitHub, Maven, Jenkins, GitHub Actions, and Docker.

## Project Structure
- `index.html` - Online Feedback Form interface
- `pom.xml` - Maven project descriptor
- `src/main/java/` - Java embedded HTTP web server and endpoints
- `src/main/resources/` - Embedded static web resources
- `src/test/java/` - Automated unit tests
